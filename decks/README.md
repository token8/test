# Decks

Presentations built on the brand masters (`brand/templates/masters.js`), so they
always match the current template, colours and logo.

| Deck | Build |
|---|---|
| `100-day-plan/`: 100-day plan & operating model (ITIL, PMI) for C-level stakeholders | `cd brand/templates && npm ci && node ../../decks/100-day-plan/build.js` |

Figures and client names in the decks are illustrative until replaced.
